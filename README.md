# ricson5499.github.io

个人网站和项目集合，包含技术文章、实用工具和小游戏。

## 📚 主要内容

- **Articles** - 技术文章（中英文）
  - AI 与生产力、就业的思考
  - Docker、Ollama、VSCode 集成
  - 架构设计模式
  - Windows、Android、WSL、Docker 相关

- **Tools** - 实用工具集
  - 美食页面（EatPage）- 食谱管理
  - 倒计时器（Countdown Timer）
  - 工资计算器（Salary Calculator）
  - 马拉松训练计划
  - 人格分析工具（MBTI、开发者人设）
  - 其他小工具

- **Games** - 小游戏
  - 塔防游戏（TD1）
  - Office Rage Simulator

- **Proto Journal** - 创意日志
  - 项目想法记录
  - 概念设计展示



## 📁 项目结构

```
├── articles/          # 技术文章
```
